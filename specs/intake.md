# intake

**Purpose.** Make sure we know the dialogue line before anything is generated — the verbatim requirement depends on it. Everything else (character, location, shots) the LLM may invent.

**Inputs.** `manifest.idea`, `manifest.params["line"]` (from `--line`), `manifest.params["lang"]`, `ctx.interactive`, `ctx.ask` (the only way to ask — tests inject it).

**Outputs.** `manifest.params["line"]`, `manifest.params["line_source"]` (`input` | `user`), `manifest.params["lang"]` when known. Data: `{"asked": bool}`.

**Behaviour.**
1. `--line` given → use it, `line_source=input`.
2. Else quoted text in the idea (`extract_quoted_line`) → use it, `line_source=input`.
3. Else if `ctx.interactive` → ask once: `Що каже персонаж? Числа — словами. (Enter — хай придумає AI): `. Non-empty answer → `line_source=user`. Empty → leave the line unset, append to `manifest.assumptions`: "line will be generated by the LLM".
4. Else (non-interactive) → leave unset, same assumption.
5. **Numbers policy:** the line must not contain digits (Ukrainian numerals inflect — we can't spell them correctly, the user can). If a known line has digits: interactive → ask to rewrite: `У репліці є цифри — напишіть числа словами (Enter — хай придумає AI): ` (repeat until no digits, max 3 times, then `GateFailed`). An answer without digits → that line, `line_source=user` (the user rewrote it, whatever its original source). An **empty answer** → same as step 3: leave the line unset, record the assumption. Non-interactive → `GateFailed("Write numbers in words in the line: ...")`.
6. `lang`: `--lang` if given, else `detect_lang(line)` when a line is known.

**Acceptance criteria.**
- `--line` wins over quotes in the idea.
- Quoted line is taken verbatim, including nested quotes of another kind and apostrophes.
- Non-interactive never calls `ctx.ask`.
- Interactive with empty answer records the assumption; at most one question when there are no digits.
- Line with digits: non-interactive → `GateFailed`; interactive → re-asked, answer without digits accepted with `line_source=user` (also when the original came from `--line`).
- Empty answer in the digit-rewrite question → line unset, assumption recorded, no `GateFailed`.
- After three failed digit rewrites → `GateFailed` whose message includes the last answer (like the non-interactive error).
- An answer that still has digits followed by an empty answer inside the rewrite loop → line unset, assumption recorded, no `GateFailed`.
- Idempotent re-run: running intake twice on the same manifest does not change `line_source` from `user` back to `input`.
- Pipeline registration: covered by `test_stages_follow_specs_order`.
